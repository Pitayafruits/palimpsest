## Palimpsest v0.2.0 · 确认文档，让两端重新一致

冲突发生后，直接在文档审阅窗口完成处理，无需寻找文件夹或手动删除同步基准。

- 三方比较，自动合并互不影响的修改，包括同一表格行中不同单元格的修改。
- 文档章节导航、相同内容折叠、差异词句高亮和完整文档预览。
- 逐处采用本地 / 网页、两段保留，或在可视化编辑器中调整内容。
- 图片缩略图、点击放大、按内容识别同图，以及不可变图片副本。
- 自动保存处理进度，稍后处理后可继续；旧版冲突也支持保守审阅。
- 确认后自动备份、检查新修改、更新两端并恢复同步。
- 写回恢复记录避免网络中断后的重复提交；部分成功时保留选择并说明当前状态。

Windows x64、macOS Apple Silicon 和 Intel 使用同一套审阅交互。Windows 完整解压 ZIP 后运行 Palimpsest.exe，Mac 将 DMG 中的 .app 复制到 Applications。

Mac 包尚未经过 Apple 公证，发行包未使用付费开发者证书签名。需要允许用户名 / 密码 Basic Authentication 的 Confluence Server / Data Center。各平台附有 SHA256SUMS 校验文件。
